# 采用表格优先的批量审阅工作区

正式 Web 端采用“高密度项目表格 + 右侧详情面板”作为主信息架构，而不是以逐条卡片或 Lists 看板作为首页。原因是工具的核心任务是从大量 Star/owned 项目中比较健康信号、筛选项目并按动作分组批量确认；表格能在同一视图中呈现多个项目的关键字段，多选和批量预览也更直接。详情面板吸收审阅队列的证据表达，Lists 保留为次级导航和筛选维度。该决策只约束信息架构，不限制后续在详情页使用卡片或在 Lists 页面使用看板。
