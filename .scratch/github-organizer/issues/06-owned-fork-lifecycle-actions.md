# 06 — owned/fork 项目与仓库生命周期动作

**What to build:** 工具扫描并展示本人拥有的仓库（包括 fork）及其关系；用户可以对自有仓库执行 Archive/Unarchive，并在高级危险操作区域删除本人拥有的原始仓库或 fork。删除必须经过完整安全护栏；他人仓库不提供删除入口，失败时保留可重试项。

**Blocked by:** 03 — 健康信号、筛选与详情建议

**Status:** ready-for-agent

- [ ] 扫描结果包含本人拥有的原始仓库和 fork，并明确显示 Owned/Fork 关系。
- [ ] 自有仓库详情面板提供 Archive/Unarchive 入口，并与普通 Star/List 动作视觉分离。
- [ ] 删除入口只对当前用户拥有的仓库出现，不对他人仓库提供删除动作。
- [ ] 删除位于高级危险操作区域，并显示不可由本工具恢复的风险说明。
- [ ] 删除前展示完整 `owner/repo`、fork/original、默认分支和最近 commit 等身份/健康证据。
- [ ] 删除前要求二次确认并输入完整 `owner/repo` 名称。
- [ ] 删除意图和元数据在调用 GitHub 前写入本地审计记录。
- [ ] 删除失败或权限不足时显示原因并保留可重试项，不自动重试、不静默移除。
- [ ] 编排 seam 的测试覆盖权限边界、删除护栏、Archive/Unarchive 和失败恢复。
