# 02 — 本地启动、gh 认证与首次 Star 扫描

**What to build:** 用户运行命令启动本地 Web 服务并打开页面后，工具检查本机 GitHub CLI（`gh`）的安装和登录状态。认证可用时，用户点击“开始扫描”即可读取当前已 Star 的项目条目，在 B 方案批量表格中看到基础关系和扫描进度；最近一次扫描结果保存到单个本地 JSON 文件。认证不可用时，页面只展示修复引导，不提供写操作入口。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 启动命令可运行本地 Web 服务，并提供明确的浏览器访问地址。
- [ ] 页面能区分 `gh` 未安装、未登录和认证可用三种状态，并给出对应引导。
- [ ] 用户显式点击“开始扫描”后才发起 GitHub 请求。
- [ ] 已 Star 项目以 B 方案表格显示，至少包含 `owner/repo`、Star 关系和基础仓库标识。
- [ ] 页面显示扫描进度、成功计数、失败计数和失败原因；失败项目不会被静默丢弃。
- [ ] 最近一次扫描结果可写入并从单个本地 JSON 文件重新加载。
- [ ] 通过扫描与动作编排 seam 的契约测试覆盖认证门禁、扫描触发和基本结果输出。
