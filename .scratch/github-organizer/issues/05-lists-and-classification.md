# 05 — GitHub Lists 与透明归类建议

**What to build:** 用户可以查看现有 GitHub Lists 及其项目条目关系，并在 B 方案的次级导航/筛选入口中管理分类。工具支持加入/移出 List、默认多归类和显式唯一归类；支持新建、重命名、删除前确认及数量统计；用户可以维护关键词/Topic/语言到 List 的透明规则并查看命中依据。

**Blocked by:** 03 — 健康信号、筛选与详情建议

**Status:** ready-for-agent

- [ ] 扫描结果展示每个项目条目当前所属的 GitHub Lists。
- [ ] 加入一个 List 默认不会移除其他 List 关系。
- [ ] “设为唯一归类”经过单独确认后才移除其他 List 关系。
- [ ] 用户可以加入 List、移出 List，并看到逐项成功/失败结果。
- [ ] 用户可以新建、重命名 List；删除 List 前必须二次确认，且不连带删除仓库或取消 Star。
- [ ] 每个 List 展示项目总数和待处理数量。
- [ ] 用户可以维护关键词/Topic/语言 → List 规则，建议展示命中的字段和目标 List。
- [ ] 未 Star 的本人拥有仓库不显示 GitHub List 写操作入口。
- [ ] 编排 seam 的测试覆盖多归类、唯一归类、List 生命周期和规则命中解释。
