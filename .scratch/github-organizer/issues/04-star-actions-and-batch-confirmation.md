# 04 — Star 整理动作与批量确认

**What to build:** 用户可以从表格多选项目，按“取消 Star”和“保留当前关系”分组预览并确认。工具逐项执行并在页面显示成功/失败结果；失败项可单独重试；本次扫描中成功取消 Star 的项目提供重新检查状态后的撤销，并把动作写入本地审计记录。

**Blocked by:** 03 — 健康信号、筛选与详情建议

**Status:** ready-for-agent

- [ ] 用户可多选项目并看到按动作分组的预览清单。
- [ ] 未经过预览和确认时，不会因为筛选条件直接执行批量动作。
- [ ] 取消 Star 和保留当前关系可分别确认，动作意图清晰可见。
- [ ] 每个项目独立记录成功或失败；局部失败不会伪造整批回滚。
- [ ] 失败项显示可理解的 GitHub 错误原因，并支持单项重试。
- [ ] 本次工具成功执行的取消 Star 可在撤销前重新读取当前 GitHub 状态后恢复 Star。
- [ ] 所有动作写入本地审计记录，包含项目、动作、时间和结果。
- [ ] 编排 seam 的测试覆盖分组预览、局部成功、重试和撤销状态检查。
